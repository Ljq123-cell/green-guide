# 大模型驱动的智能垃圾分类AI教育科普助手 —— 研究报告

---

## 一、研究背景与意义

### 1.1 政策背景

随着我国城镇化进程加速，城市生活垃圾产生量持续增长。住房和城乡建设部数据显示，截至2025年底，全国297个地级及以上城市已基本实现生活垃圾分类全覆盖，21个省份、173个城市出台了地方性法规或政府规章。2025年8月，《中共中央国务院关于推动城市高质量发展的意见》明确提出"深入推进城市生活垃圾分类，推动分类网点与再生资源回收网点衔接融合"，垃圾分类已上升为国家战略。

以上海市为例，自2019年《上海市生活垃圾管理条例》施行以来，垃圾分类工作成效显著。截至2025年，可回收物日均回收量达7,927吨，较条例实施前增长1.96倍；有害垃圾日均分出量增长13.6倍；湿垃圾日均分出量增长59%；干垃圾日均处置量减少16.7%。居住小区和单位分类达标率稳定在95%以上，生活垃圾回收利用率达45.3%。2024年出台的《上海市无废城市建设条例》更是全国首部省级无废城市地方法规。此外，上海建成了1.5万余个可回收物服务点、644个惠民回收服务点，部署智能回收箱2,989个，"沪尚回收"小程序注册用户超50万人。

这些数据表明，政策驱动下的垃圾分类基础设施已日趋完善，但**公众教育仍面临严峻挑战**：如何让居民从"被动分类"转向"主动参与"？如何降低垃圾分类知识的学习门槛？如何持续激发公众的环保意识？这些问题呼唤技术创新来提供解决路径。

### 1.2 社会痛点

尽管垃圾分类政策推行多年，公众在实际操作中仍面临诸多困难：

1. **分类知识复杂且更新频繁**：不同城市分类标准存在差异（如上海采用"干湿分类"，北京采用"其他/厨余"），居民难以准确记忆和判断。贝壳、榴莲壳等质地坚硬的物品常被误归为厨余垃圾，实则属于其他垃圾。

2. **传统科普方式效果有限**：宣传单页、社区讲座等单向传播方式参与度低，缺乏互动性和个性化反馈，知识转化率不高。

3. **学习动力持续性不足**：缺乏有效的激励机制和游戏化体验，居民容易在"分类新鲜期"过后回归旧习惯。

4. **老年人和儿童群体覆盖困难**：这两类人群是家庭垃圾分类的重要参与者，但传统科普方式对文字阅读能力较弱的群体不友好。

### 1.3 技术机遇

2024-2025年，大语言模型（Large Language Model, LLM）技术进入快速发展期。以DeepSeek、GPT-4等为代表的大模型在自然语言理解、知识推理和内容生成方面展现出前所未有的能力。这些能力为构建智能化、个性化、交互式的垃圾分类教育科普工具提供了全新的技术可能：

- **自然语言对话**：用户可以用日常语言描述垃圾物品，大模型准确理解并给出分类结果和理由，降低使用门槛。
- **个性化知识讲解**：根据用户的知识水平和错误模式，自动生成针对性的知识解析和纠正反馈。
- **智能内容生成**：自动生成科普文章、趣味问答和环保知识推送，大幅降低内容运营成本。
- **多轮互动引导**：通过对话式教学，引导用户逐步构建系统的垃圾分类知识体系。

### 1.4 研究意义

本研究的意义体现在理论与实践两个层面：

**理论层面**，探索了大语言模型在环保教育垂直领域的应用范式，验证了"LLM+教育"技术路线在垃圾分类科普场景中的可行性和有效性，为AI辅助公众科学素养教育提供了参考案例。

**实践层面**，设计并实现了集AI智能分类、科普知识传播、趣味答题互动、成就激励于一体的垃圾分类教育科普助手系统，以微信小程序形态触达大众用户，有望为提升公众垃圾分类意识和能力、推动垃圾分类政策落地提供技术支撑。

## 二、国内外研究现状

### 2.1 国外研究现状

在国际学术界，大语言模型赋能垃圾分类教育是2024-2025年的新兴研究方向，以美国圣塔克拉拉大学（Santa Clara University）Qiming Sun和I-Han Hsiao团队的研究最具代表性。

**Waste Genie系列平台**是该方向的核心成果。Waste Genie（2023-2024）是一个基于Web的AI教育平台，集成GPT-3.5提供垃圾分拣互动测验与AI个性化反馈，通过2周用户研究（21名大学生参与）验证了可持续意识提升的有效性。在此基础上，Waste Genie+（2025）引入了**环境立法引导的大语言模型（EL-LLM）**多智能体架构，将加州12部复杂环保法规（最长法案达26,640词，Gunning Fog可读性指数13-17，相当于大学阅读水平）自动转化为易于理解的微型学习内容。10天用户研究显示，AI生成的微型内容在可读性、信息量、连贯性和法律信息保留度上均表现优异，参与者垃圾分类准确率从79%提升至83%。

该团队还探索了**GPT引导的自适应反馈机制**（2024），在54名参与者、4,914次垃圾分类行为的实验中发现，AI代理在用户分类错误时提供提示而非直接给出答案，能有效提升学习效果，低水平学习者受益尤为显著。另外，**人-AI协作学习**研究（IEEE ICALT 2025）发现，主动修改AI建议的用户比直接复制AI输出的用户产出质量更高，揭示了人机协作在环保教育中的最佳实践模式。

除Waste Genie系列外，相关方向还包括：增强现实（AR）垃圾数据可视化提供生态反馈、深度学习的垃圾分类检测（EfficientNet等模型）、以及面向儿童的机器人游戏化教育（ROBOTE）等。

### 2.2 国内研究现状

国内垃圾分类研究主要集中在政策执行和工程技术两个维度，**将大语言模型与垃圾分类教育科普深度结合的学术研究尚处于起步阶段**。

在政策层面，住建部推动297个地级及以上城市基本实现垃圾分类全覆盖，46个重点城市率先建立较完备的分类投放、收集、运输、处理体系。全国无害化处理率达99.9%，焚烧处理能力占比78.1%，15个省市实现原生垃圾"零填埋"。然而，区域发展不平衡问题突出：经济发达城市分类效果显著，但老旧小区和县域地区仍存在短板；厨余垃圾占比50%-60%但处理成本高；废玻璃回收率不足40%，废旧纺织品回收率不足25%。

在技术应用层面，智能垃圾分类以**图像识别**为主流技术路线，通过卷积神经网络（CNN）对垃圾图像进行分类。但纯图像识别受限于拍摄角度、光照条件和复合材质物品，准确率难以达到实用要求。2024年，北京邮电大学人工智能学院的"绿邮先锋"项目开始探索基于大模型的垃圾分类微信小程序应用，通过大模型技术提升分类准确性，并融入碳减排知识科普，标志着国内高校在该方向的初步探索。

### 2.3 现有研究的不足

综合国内外研究现状，现有工作存在以下不足：

1. **技术路线单一**：多数系统依赖纯图像识别，对复杂物品（如复合包装、特殊废弃物）的识别能力不足，且缺乏对分类理由的解释能力。

2. **教育与技术割裂**：现有垃圾分类系统侧重"分类工具"定位，忽视"教育科普"价值，缺乏系统化的知识学习和用户成长体系。

3. **个性化缺失**：内容推送和反馈缺乏对不同用户知识水平、学习偏好和错误模式的适应性调整。

4. **国内LLM+垃圾分类教育空白**：国外Waste Genie系列展示了LLM在垃圾分类教育中的巨大潜力，但基于中文环境和中国垃圾分类标准（四分类法）的同类研究尚属空白。

5. **缺乏完整的激励机制**：现有系统缺乏将学习行为、分类实践与成就激励有机结合的闭环设计。

## 三、研究目标与内容

### 3.1 研究目标

本项目旨在**设计并实现一个以大语言模型为核心驱动力的智能垃圾分类AI教育科普助手系统**，具体目标包括：

1. 构建基于大语言模型的智能垃圾分类问答引擎，实现对用户自然语言描述的垃圾物品进行准确分类，并生成个性化的知识讲解。
2. 建立垃圾分类科普知识内容体系，涵盖可回收物、有害垃圾、厨余垃圾、其他垃圾四大类别，提供富文本文章、分类速查、趣味答题等多元学习形式。
3. 设计学习激励闭环，通过积分体系、成就徽章、排行榜等游戏化机制，持续激发用户学习动力。
4. 以微信小程序形态交付前端，便捷触达大众用户，服务社区和校园垃圾分类教育场景。

### 3.2 研究内容

**（1）大模型驱动的智能垃圾分类问答**

调用DeepSeek大语言模型API，设计垃圾分类专用提示词（Prompt）模板，实现以下功能：接收用户以自然语言描述的垃圾物品名称或特征，返回分类结果（可回收物/有害垃圾/厨余垃圾/其他垃圾）、分类依据说明和投放指导建议。通过提示词工程约束输出格式，确保分类结果的准确性和一致性。

**（2）科普知识内容管理与推送**

设计科普文章的内容模型（标题、摘要、正文、分类标签、来源等），在数据库中存储10篇以上涵盖四大垃圾类别的科普文章，支持按类别筛选和详情查看。预留AI自动生成科普内容的扩展接口。

**（3）趣味答题与智能反馈**

设计选择题题库（支持单选和判断题），涵盖入门、进阶、挑战三个难度等级。实现随机抽题、答题计时、即时正误判断和知识解析展示。每道题附带详细的解析说明，帮助用户在答错时理解正确分类逻辑。

**（4）用户成长与激励体系**

设计积分系统（搜索+1、答对+5、连续登录+10等规则）、成就徽章（如"分类新手"——首次识别、"分类达人"——累计100次识别、"学霸"——正确率90%+等）和积分排行榜，形成"学习→实践→反馈→激励"的闭环。

**（5）微信小程序前端与后台管理**

前端以微信小程序形态交付，提供AI分类、科普浏览、答题闯关、个人中心等功能。后台管理端提供文章管理、题库管理、用户反馈管理等功能，支持管理员对内容进行CRUD操作。

## 四、技术路线

### 4.1 系统架构

系统采用**前后端分离**的三层架构：

- **前端层**：微信小程序（用户端）+ 管理后台Web页面（管理员端）
- **服务层**：Spring Boot 3.2.5 RESTful API服务，集成Spring Security + JWT身份认证
- **数据层**：MySQL 8.0关系型数据库 + MyBatis-Plus ORM框架
- **AI层**：DeepSeek API（deepseek-chat模型）提供大语言模型能力

### 4.2 技术选型

| 层级 | 技术 | 选型理由 |
|------|------|----------|
| 后端框架 | Spring Boot 3.2.5 | 成熟稳定的Java企业级框架，生态丰富 |
| ORM | MyBatis-Plus 3.5.5 | 简化CRUD操作，支持分页和逻辑删除 |
| 数据库 | MySQL 8.0 | 关系型数据存储，支持全文索引和JSON字段 |
| 连接池 | Druid 1.2.20 | 高性能数据库连接池，内置SQL监控 |
| 认证授权 | Spring Security + JWT | 无状态认证，支持管理员和普通用户双角色 |
| AI引擎 | DeepSeek API | 国产大模型，性价比高，中文理解能力强 |
| 工具库 | Lombok / Hutool | 减少模板代码，提供通用工具方法 |
| JDK | Java 17 | LTS版本，支持现代Java特性 |

### 4.3 核心功能流程

**AI智能分类流程**：用户输入垃圾物品描述 → 系统构建垃圾分类专用提示词 → 调用DeepSeek API → 解析返回结果（分类类别、依据说明、投放指导）→ 记录学习行为 → 更新用户积分。

**答题学习流程**：系统随机抽取题目 → 用户选择答案 → 系统即时判断正误 → 展示知识解析 → 记录答题结果 → 更新积分和统计 → 检查成就解锁条件。

**科普浏览流程**：用户选择类别 → 系统查询已发布文章 → 分页展示列表 → 用户点击查看详情 → 富文本渲染展示 → 记录浏览行为。

### 4.4 数据库设计

系统设计了11张核心数据表：管理员用户表（admin_user）、普通用户表（user）、科普知识文章表（knowledge_article）、题库表（quiz_question）、答题记录表（quiz_record）、用户反馈表（user_feedback）、学习记录表（learning_record）、积分记录表（user_points）、成就定义表（achievement）、用户成就表（user_achievement）、垃圾分类知识库表（garbage_category）。数据库采用utf8mb4字符集，对高频查询字段建立索引，对文章标题和内容建立全文索引以支持搜索功能。

## 五、主要创新点

### 5.1 大语言模型驱动的交互式科普范式

区别于传统的单向知识传播方式，本项目利用大语言模型的自然语言理解和生成能力，实现了**对话式、解释性的垃圾分类指导**。用户无需记忆复杂的分类规则，只需用日常语言描述物品，系统即可给出分类结果并有针对性地解释分类依据。这种"可对话的科普"模式显著降低了知识获取门槛，尤其惠及文字阅读能力较弱的老年人和儿童群体。

### 5.2 "教学评一体化"的闭环学习设计

系统将**知识学习（科普文章）、实践练习（AI分类识别）、效果检测（趣味答题）、反馈激励（积分+成就+排行）**四个环节有机串联，形成完整的教育闭环。每个环节产生的行为数据都实时反馈到用户画像中，驱动个性化内容推送和难度适配。这种设计契合了"做中学"（Learning by Doing）的教育理念，使垃圾分类学习从"被动接收"转变为"主动探索"。

### 5.3 知识学习与环保行为激励的深度融合

系统创新性地将用户的每一次学习行为（阅读文章、识别垃圾、答对题目、连续登录）转化为可量化的积分和成就进度，并通过排行榜营造良性竞争氛围。这种游戏化设计将抽象的环保知识学习转化为具体的、即时的正向反馈，有效解决了环保教育中"知易行难"的动机持续性难题。

### 5.4 面向中国垃圾分类标准的本地化适配

系统完全基于中国"四分类法"（可回收物、有害垃圾、厨余垃圾、其他垃圾）标准设计，并特别关注了国内常见分类误区（如大棒骨≠厨余垃圾、榴莲壳≠厨余垃圾、创可贴≠有害垃圾等）。AI提示词模板内嵌了中国垃圾分类政策和常见误区知识，确保输出内容符合国内标准，填补了国外同类研究在中国本地化适配方面的空白。

## 六、总结与展望

本项目设计并实现了一款以大语言模型为核心驱动力的智能垃圾分类AI教育科普助手。系统通过AI智能分类问答、科普知识传播、趣味答题互动和游戏化激励四大核心功能模块，构建了"学习-实践-检测-激励"的教育闭环，旨在降低垃圾分类知识的学习门槛，激发公众的环保意识和持续参与动力。

未来工作可从以下方向展开：引入多模态识别能力（拍照识别+大模型推理的联合决策），增强对复杂物品的分类准确率；探索AI自动生成个性化科普内容，降低内容运营成本；基于用户学习行为数据训练推荐模型，实现千人千面的学习路径规划；拓展多终端覆盖（智能音箱语音交互、校园一体机等），服务更广泛的用户群体。
